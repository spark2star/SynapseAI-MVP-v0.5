# Chrome DevTools Integration

When debugging frontend issues, testing UI behavior, or verifying visual changes, use the Chrome DevTools MCP tools to inspect the actual running application.

## When to Use Chrome DevTools

- Verifying UI changes and visual regressions
- Debugging frontend JavaScript errors or console warnings
- Testing user workflows and interactions
- Inspecting network requests and API responses
- Validating form submissions and data flow
- Checking responsive design and layout issues

## Best Practices

1. Take snapshots before screenshots to get structured page content
2. Use `list_console_messages` to check for JavaScript errors
3. Use `list_network_requests` to verify API calls and responses
4. Test critical user flows end-to-end when making changes
5. Verify changes in the actual browser rather than assuming correctness from code alone
